# Saheli local RAG + one bilingual voice button patch

This patch is designed for `feature/voice-faq-workstream-b` only. It does not change GitHub by itself and does not touch `main`.

## What it adds

- One microphone button for English, Hindi, and mixed speech; no voice-language selector.
- Local speech transcription through Transformers.js Whisper (model downloads once, then is cached).
- Multilingual sentence embeddings over the existing curated `src/content/faq.js` data.
- Retrieval-augmented answers using the selected curated FAQ answer and its source URL (extractive RAG; no LLM generation and no paid API).
- Lightweight intent/category detection and conservative low-confidence fallback.
- Existing `matchFaq()` remains the fallback if the local server is not running.

## Important limitations

- First run needs internet to download npm packages and model files. After caching, model inference can run locally; do not claim the first setup is fully offline.
- The Whisper base model is still a substantial download and needs RAM/CPU. The server converts browser-recorded audio to mono 16 kHz WAV using the `ffmpeg-static` package before transcription; verify that the packaged FFmpeg binary works on your operating system.
- Answers are retrieved from curated FAQs, not generated by an LLM. This is intentional for a safer no-paid-API first version.
- Similarity thresholds need evaluation against real paraphrases; similarity is not a medical confidence score.

## Apply safely on your branch

1. In your terminal, check your branch and worktree first:

   ```bash
   git status
   git switch feature/voice-faq-workstream-b
   git pull origin feature/voice-faq-workstream-b
   ```

2. Back up the current `src/components/FaqAssistant.jsx` before replacing it. Copy the `src/components/FaqAssistant.jsx` and `src/lib/language.js` files from this patch into the matching paths.
3. Copy `server/index.js` into a new `server/` directory.
4. Install dependencies from the repository root:

   ```bash
   npm install express cors multer @huggingface/transformers ffmpeg-static
   ```

5. Add these scripts to the existing `package.json` `scripts` object (preserve all existing scripts):

   ```json
   "server": "node server/index.js"
   ```

6. In `vite.config.js`, add a dev-server proxy to the existing config (do not overwrite other config):

   ```js
   server: {
     proxy: {
       '/api': 'http://localhost:8787'
     }
   }
   ```

7. Run in two terminals:

   ```bash
   npm run server
   npm run dev
   ```

   Open the Vite URL, allow microphone access, and try both text and voice.

8. Verify:

   ```bash
   npm run lint
   npm run build
   ```

## Manual test cases

- `Why is my period late?`
- `मेरी माहवारी देर से क्यों आ रही है?`
- `Mera period late hai, what should I do?`
- `How do I use a pad?`
- `मुझे बुखार और निचले पेट में तेज़ दर्द है।`
- A completely unrelated question should trigger the low-confidence fallback.

Do not enter real patient-identifying or sensitive health data during development. Do not merge until the team reviews and tests the patch.
